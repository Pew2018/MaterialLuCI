# MaterialLuCI 0.2 网页适配

在 feature/classic-native-v1 继续开发，未合并 main。

## 设计与功能边界
保持上传规范的经典 Material / OxygenOS 视觉语言、小圆角和克制反馈。
网页采用桌面侧栏和手机抽屉，替代原模块专用三项底栏与全局 620px 限宽。
菜单来自 ui.menu；保持 ACL、名称、链接和排序。侧栏只接收原前两层菜单，后续层级保留页面顶部标签。
不改 LuCI 字段、后台选项、RPC、保存及应用逻辑。保留原 select 和复选选项组。

## 一致性
桌面通用按钮 36px，触摸环境 48px；页面提交按钮保留 48px。
使用共享色彩角色定义悬停、按压、禁用、危险操作；修复旧主题浅灰标签悬停覆盖。
表格局部横向滚动，五列以上提供更宽最小宽度，不隐藏列或重新排序。
外观在原路由器主题选择项后以默认折叠区提供，仅保存浏览器偏好。

## 输入法
正文使用自然文档滚动，不强制设置 body 为 visualViewport.height。
VisualViewport 的尺寸和 offset 仅用于定位抽屉和弹窗；弹窗在可见区域内滚动。
手机输入字号 16px，保留浏览器缩放；焦点修正在输入及键盘 resize 后执行，不在每次滚动执行。
原 LuCI 弹窗仍由 LuCI 管理，本主题只增强样式。

## 验证范围与限制
Actions 使用固定版本真实 LuCI JS 与 Lua 模板，模拟数据及菜单测试 Chromium、WebKit。
覆盖侧栏顺序和链接、原 select 与 Checkbox、提交值、宽表、按钮状态、弹窗、缩小视口和 VisualViewport 事件。
自动化模拟键盘尺寸不能等价于 iOS/Android 真机输入法；路由器专用插件只有实际设备验证才能最终确认。
安装产物只上传目标架构 IPK，GitHub 下载 ZIP 解压后安装，不能改扩展名。

## 0.2.1 设备截图回归
- 构建生成独立菜单模块名和资源缓存标识，避免旧分组三项菜单模块与侧栏代码混用。
- 菜单路径缺少 dispatchpath 时兼容 requestpath。
- 移除 theme-color 元数据和浏览器颜色更新，浏览器界面由浏览器自己管理。
- 加入真实上游 opkg 页面回归，其 CSS、表格和旧 div.btn 控件不再仅由简化样例代替。
- 保留软件包功能、字段和操作顺序；按钮避免竖排、输入组合避免相互覆盖。
