发布日期记录：2026-10-13（Asia/Hong_Kong）。首个正式版本，正式发布由仓库维护者完成。

## 实现范围

一个 IPK 提供 Classic 与 M3E 风格，共享原生 LuCI 菜单、表单、路由、RPC 和保存应用流程。包含固定顶栏、桌面侧栏、手机抽屉、原生标签页、宽表格局部横向滚动、卡片、明暗模式、强调色及标题/设备名称个性化设置。

Classic 使用官方 MDC Web 与原生适配；M3E 使用官方 Material Web 2.5.0 的部分组件与 Material Color Utilities 配色，结合主题自己的 Expressive 样式。M3E 波浪进度条为项目实现，不是官方 Expressive Web 组件。文本框和下拉菜单继续使用 MDC/原生适配。

## 滚动相关修复

| 路径 | 实际调整 | 主要影响 |
| --- | --- | --- |
| Branding | 分开标题内容、设备名称与颜色更新；缓存相关外观状态，合并计算样式读取，跳过相同属性/样式写入 | 业务更新、输入焦点、抽屉/弹窗 |

修复保留首次绘制前的卡片布局、动态字段发现、空表后续填行、图表延迟完成、节点移动、fieldset 状态恢复和 bfcache 恢复契约。没有降低业务轮询频率、更换滚动容器、关闭全部涟漪或移除官方组件。

用户已确认明显性能改善。尚无用户设备的 Paint/Raster/Composite 录制，因此不宣称已证明所有静态滚动的掉帧根因，也没有盲改阴影、圆角、Shadow DOM、合成策略或波浪动画。

## LED 缩写修复

上游 LuCI openwrt-21.02 的 `view/system/leds.js` 在标题、说明和表头使用 `<abbr title="Light Emitting Diode">LED</abbr>`。WebKit 默认对 `abbr[title]` 应用点状文字下划线，主题中没有对应的缩写边框规则。

当前主题依据已核实的 `admin/system/leds` 路由标记，仅通过 `#maincontent[data-ml-page=leds] abbr[title]` 覆盖 `text-decoration`。保留缩写、title 说明、LED 配置业务和其他页面的文字装饰；不重置链接、输入底线或标签页指示器。

## 构建与验证

- 从 `theme/root` 打包；保留重复 `root` 目录，不覆盖其内容。
- 版本、架构与目标来自 `theme/package.json`；资源缓存以版本和提交标识更新。
- 默认 build.yml 保持语法/模板检查、轻量行为回归、IPK 打包、结构/资源/许可证/提交身份/哈希/缓存检查及安装包与清单上传。
- 轻量回归覆盖 branding 更新边界、适配器分发、动态字段、表格/图表分类、首次卡片布局、控件生命周期、输入法及 LED 样式范围。
- 默认流程不安装浏览器、不恢复截图矩阵或长时间性能采样。
- 行为夹具不是实际 CSS 渲染或真机性能验证。全部插件兼容、真实业务操作及其他固件环境不在本次声明范围内。
