# Classic Native 0.1.1 实现记录

代码位于 feature/classic-native-v1，不合并 main。构建产物为唯一 aarch64_cortex-a53 目标 IPK。
本版修复安装包缺失父目录条目导致 opkg 无法写入模板和静态资源的问题；升级版本号为 0.1.1-1，便于替换已安装的 0.1.0-1。
Actions artifact 只上传 IPK，不上传安装文档、清单、校验文件或预览截图。安装文档不保存用户的 SSH 端口或路由器地址。

使用用户导出的 bootstrap_mod 兼容规则（保留版权）并以独立 cascade 覆盖其视觉；构建时合并样式，取消额外 @import。
Lua header/footer/sysauth 保留 LuCI 模板环境和原登录 POST/HTTPS探测；不覆盖 cbi/ui/form/menu-bootstrap 等共享核心文件。

## 完成的设计能力

- 56 px 顶栏/底导航，620 px 内容，24 px 平面边距。
- 完整浅深系统、20预设、自定义HEX、卡片、顶栏/标题/图标着色。
- 用户规范的 OKLab 角色算法与按下固定前景策略。
- 28×10轨道 /16滑块 /48触摸区域，原真实 checkbox 和事件保留。
- 单选自绘 dialog，保留 select 作为值和验证来源；兼容 LuCI UISelect.setValue 设置 option.selected。
- input submit 保留原节点，用外层反馈，不丢失提交行为。
- 控件确认点按涟漪；滚动祖先、disabled、reduced motion 检查。
- 原生页面导航不改 SPA；仅同页外观/弹窗使用临时历史。草稿 DOM 不卸载。
- 紧凑对话框与原 LuCI modal 样式；不替换其 showModal/hideModal。
- 动态增强范围限 maincontent 和 LuCI modal；不全页反复扫描。
- 表格局部滚动，日志可选复制，状态数值中性，进度条数值与条体分离。

## 适配边界

复杂多选/搜索和插件自带组件保留功能再统一样式；不是所有输入都变为独立字段编辑页。
不重写状态页业务，不伪造真实网络状态。三入口通过动态菜单 dialog 选原页面，而非持久单页 tab 容器。
当前没有其他风格；palette/startup/feedback/app/menu 的分离为后续 renderer 提供边界，未声称已实现多风格注册系统。

## 构建与检查

原始文件在 GitHub 维护，构建仅 Actions：
- JS/shell 语法。
- 536 种 seed 的浅/深主次按钮正常/按下与控件对比度。
- 本地 JS minify，Lua模板语法与样例渲染。
- IPK 数据归档显式包含所有父目录，并检查每个文件的父目录条目、路径白名单和 A53 架构。
- 固定上游 LuCI commit e4c46338b196e486a88b1a75b78e283708c82bc4 的真实JS，mock只读RPC和菜单。
- Chromium/WebKit 的值、事件、提交、disabled、modal、外观、返回、草稿、响应式与登录；视口覆盖手机、平板和桌面。
- 预览明确标注模拟数据，实际路由器运行尚待用户验证。

上游 LuCI JS仅用于 CI，不打包进主题，不替换设备已安装版本。
