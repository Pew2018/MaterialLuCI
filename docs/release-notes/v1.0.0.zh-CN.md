# MaterialLuCI 1.0.0 — 首个正式版本

MaterialLuCI 是面向小米 AX3000T / ImmortalWrt 21.02 Lua LuCI 的 Material 风格主题。本次发布提供 Classic 与 M3E 两种可切换外观，所有运行资源本地打包，无需 CDN。

## 主要功能

- 固定顶栏、桌面侧栏和手机抽屉，保留 LuCI 原生菜单、页面标签和导航。
- Classic 经典 Material 外观，以及结合官方 Material Web 组件与语义配色的 M3E 外观。
- 浅色、深色、跟随系统，自定义强调色、卡片和额外着色范围。
- 自定义顶栏标题与文字颜色；侧边栏设备名称可隐藏或自定义。
- 官方涟漪、开关及选择控件适配，加载与等待反馈，手机输入法适配。
- 宽表格局部横向滚动，兼顾原生表单、嵌套 SectionValue 与旧式备份恢复布局。

## 本次优化

- 减少滚动及业务更新期间无关的标题颜色计算、控件发现和卡片结构扫描。
- 优化输入法关闭后仍保留焦点时的视口更新，避免普通滚动持续写入根几何变量。
- 修复 LED 配置标题、说明和表头的点状下划线，保留缩写说明和原生配置功能。
- 已测试开发版本收到用户反馈：滚动性能有极大提升。

M3E 的波浪进度条由本项目实现；Material Web 提供的是 Material 3 组件，不代表整套界面均由官方 Expressive Web 组件实现。

## 安装

本次安装包：

`luci-theme-materialluci_1.0.0_aarch64_cortex-a53.ipk`

适配目标为 **小米 AX3000T / ImmortalWrt 21.02 Lua LuCI，aarch64_cortex-a53 / mediatek/mt7981**。其他固件、架构及全部第三方插件尚未完成兼容验证。

将 IPK 上传至路由器并安装，在 LuCI「系统 → 系统 → 语言和界面 / 语言与样式」选择 MaterialLuCI，保存并应用后刷新。Actions 下载的 ZIP 需要先解压，安装其中的 IPK。

主题外观设置位于原主题选择项之后。偏好仅保存在当前浏览器；切换 Classic/M3E 后在下次完整页面加载生效，请先保存业务修改。

安装、升级与回退方法见 [安装文档](https://github.com/Pew2018/MaterialLuCI/blob/main/docs/INSTALL.md)。
